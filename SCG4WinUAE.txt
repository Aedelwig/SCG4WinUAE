================================================================================
                    Swift Configuration Generator For WinUAE                    
                                   (SCG4WinUAE)                                 
================================================================================


1. INTRODUCTION
--------------------------------------------------------------------------------
WinUAE is the most comprehensive Amiga emulator available, featuring a vast
array of options to tweak. While this flexibility is ideal for advanced users,
it can be overwhelming for new users or those who prefer a quick setup without
navigating complex menus. 

Although WinUAE provides a built-in "Quickstart" interface for standard Amiga
models, SCG4WinUAE expands on this concept by offering a streamlined setup
process while keeping WinUAE's core functionality intact—resolving common setup
hurdles like display scaling and window sizing automatically.

SCG4WinUAE aims to be the simplest and most intuitive interface for generating
optimized, easy-to-edit configurations for WinUAE.

Note: SCG4WinUAE can be used as a launcher, but it is not intended to be a full
replacement for WinUAE. For advanced emulation options beyond the scope of this
program, please refer to the native WinUAE interface.


2. REQUIREMENTS
--------------------------------------------------------------------------------
- A Windows-based computer capable of running Amiga emulation.
- WinUAE installed on your system.


3. FEATURES
--------------------------------------------------------------------------------
- Portable: Can be run from any location on your system.

- Auto-Scan: Automatically detects WinUAE's location, including Configuration,
  Kickstart ROM, and Media folder locations (unless customized via the 'Edit'
  menu).*

- Smart Window Sizing: Windowed mode size is automatically calculated based on
  your desktop resolution.

- Resolution Scaling: Fullscreen mode is scaled according to your display
  resolution.

- Chipset Selection: Automatically selected for every Amiga model based on the
  loaded Kickstart ROM.

- Kickstart ROM Detection: Automatic ROM version detection based on filename.**

- Optimized Profiles: Pre-tuned configuration settings for all major Amiga
  systems.

- JIT Compiler Switch: Built-in JIT compiler toggle to boost performance on
  Motorola 68020+ systems.

- XBR Shader Integration: XBR shader-backed display output for sharp pixel
  smoothing without blurriness.

- Multi-Media Support: Load multiple disk images for Floppy, Hard Disk, or
  Compact Disk media.***

- Input Layouts: Supports multiple joystick configurations, including 2-player
  setups and gamepads.****

- Calibrated Floppy Audio: Floppy drive sound effects are enabled and pre-set
  to a pleasant volume level.

- Clean Output Files: Generated configurations can be further tweaked easily in
  WinUAE, Notepad, or any text editor.

--------------------------------------------------------------------------------
* If WinUAE paths are set to relative mode, only subdirectories will be detected
  correctly. Folder auto-detection does not work in portable mode. However, the
  main WinUAE location will always be detected, and file paths can always be
  customized manually via the Edit menu.

** Refer to Section 4 for exact Kickstart ROM naming conventions.

*** Many legacy Amiga games do not support multiple floppy drives. Multi-disk
    titles may still require manual disk swapping via the WinUAE interface:
    Host > Disk Swapper.

**** To view or adjust Joystick configurations, refer to:
     Joystick > Layout Mapping.


4. IMPORTANT NOTES
--------------------------------------------------------------------------------
- Custom Paths:
  Kickstart ROM, media image, and configuration file paths can be customized
  from the Edit menu. These settings will persist across WinUAE location
  re-scans.

- Configuration File Structure:
  The configuration files generated by this program include only essential
  system parameters, making manual editing straightforward. The files are
  structured in the following order:

      1. Joystick
      2. Graphics
      3. CPU/Chipset
      4. RAM/FPU
      5. CPU Speed
      6. MMU or JIT
      7. Kickstart
      8. Optional: Floppy Drive(s)
      9. Optional: Hard Disk(s)
     10. Optional: Compact Disk

  Note: Options not included in these simplified configurations must be
  accessed within WinUAE. Saving these configurations directly within WinUAE
  will overwrite the simplified format with WinUAE's full parameter set.

- Kickstart ROM Naming Conventions:
  Any file added to the Kickstart selection dialog must follow specific naming
  conventions to be properly recognized by SCG4WinUAE:

      Kick[version].* or amiga-dos-<version>
      --> Recognized as 'Kickstart Loaded'

      Kickstart <version> [subversion]
      --> e.g., 'Kickstart 1.3 34.5'

      (Legend: <> = Required, [] = Optional, * = Wildcard extension)

- Chipset Triggers:
  Certain chipsets require specific terms in the Kickstart image filename to
  trigger correctly:
  - '1.3' or '13' triggers the A500 chipset (OCS/ECS).
  - '2.05' or '205' triggers the A600 chipset (ECS).
  - Otherwise, the default chipset fallback is A500+.

- CDTV / CD32 System Triggers:
  CDTV or CD32 hardware profiles can be triggered on any 68k selection,
  overriding the default chipset setup. To enable this:
  1. Use Kickstart 1.3 or Kickstart 3.1 (40.60) with 'CDTV' or 'CD32' included
     in the filename (e.g., "Kickstart 3.1 (CD32).rom").
  2. Include the corresponding Extended ROM file with 'Extended' or
     'Extension' in its filename (e.g., "CD32 ROM Extension.rom").

  If the Kickstart filename contains 'CDTV' or 'CD32', SCG4WinUAE will open the
  Kickstart ROM Extension dialog. This can be bypassed if no extended ROM is
  intended for addition. Accidental selections will be ignored if filenames do
  not match the required convention.

- Shader Performance:
  The included XBR Shader can be slightly more resource-intensive, but it effectively
  counters the blurriness caused by standard monitor scaling routines.

- Generated Configuration Naming Format:
  Configuration filenames follow this structure:

      [1st Disk Name]_[Chipset]_[CPU][Flags]_[Multiplayer]

      Example Breakdown:
      - 1st Disk Name: Name of the first attached media image in priority
        order (HD -> CD -> Floppy).
      - Chipset: OCS, ECS, or AGA.
      - CPU: Ending two digits of the 68k CPU (e.g., 20 for 68020).
      - Flags: 'W' for Windowed, 'F' for Fullscreen, 'S2X' if Scale2X is enabled.
      - Multiplayer: Appended if 2-player mode is active.

- Media Sorting:
  When selecting multiple media images, they are assigned to drives in
  alphanumeric order. If this alters the intended boot order, either rename
  the files before generating the configuration or edit the drive assignments
  directly in a text editor (Notepad).

- Compact Disk Button:
  The Compact Disk button is only enabled when an AROS Kickstart or CDTV/CD32
  Kickstart Extension is loaded, as only these configurations support CD drive
  emulation.

- Omission of 68060 CPU:
  The exclusion of the Motorola 68060 processor is intentional. While it is a
  capable CPU, 68020 through 68040 setups combined with JIT compilation offer
  optimal compatibility and performance for the scope of this utility.
